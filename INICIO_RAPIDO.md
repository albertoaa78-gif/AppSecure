# 🚀 INICIO RÁPIDO - AppSecure GitHub Pages

## ⭐ SI SOLO TIENES 5 MINUTOS

```bash
# 1. Cámbiate a la rama correcta
git checkout github-pages-static

# 2. Instala dependencias (primera vez)
npm install --legacy-peer-deps

# 3. Compila para GitHub Pages
bash build-gh-pages.sh

# 4. Sube a GitHub
git add -A
git commit -m "Deploy: AppSecure"
git push origin github-pages-static

# 5. En GitHub: Settings → Pages → Branch: github-pages-static, Folder: /docs

# 6. Espera 2 minutos y accede a:
# https://albertoaa78-gif.github.io/AppSecure/
```

**¡Listo!** Tu app está publicada. 🎉
